# TranslateTheThings by [Instafluff](https://www.instafluff.tv/)

A private translator that runs in your browser. Choose Everyday (~0.9 GB) or Premium (~3.1 GB, requires WebGPU). Models download only when you confirm; your text stays on your device.

**Develop:** With Node.js 20+, run `npm ci` and `npm run dev`.

**Publish:** Run `npm test` and `npm run build`, then commit and push your changes, including the generated `assets/` folder, to `main`. In **Settings → Pages**, choose **Deploy from a branch → `main` → `/(root)`**.
